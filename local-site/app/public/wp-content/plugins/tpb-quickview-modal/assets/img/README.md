# TPB QuickView Modal - Fallback Images

This directory contains fallback images for the TPB QuickView modals.

## Required Images

Replace these placeholder files with actual product images:

1. **fallback-flower.jpg** - Flower Station hero image
2. **category-station-hero.jpg** - Category Station hero image
3. **quickcheckout-hero.jpg** - Quick Checkout Station hero image
4. **menu-boards-hero.jpg** - Menu Boards hero image
5. **branded-station-hero.jpg** - Branded Station hero image

## Recommended Specifications

- Format: JPG (preferred) or PNG
- Dimensions: 800x600px minimum (maintain aspect ratio)
- File size: Keep under 200KB for fast loading
- Quality: 80-85% compression

## Usage

These images are used as fallbacks when:
- Product has no featured image
- Product has no gallery images
- AJAX image fetch fails
- Product ID is 0 or invalid
